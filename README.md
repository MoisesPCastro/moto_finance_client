# 🏍️ Moto Finance - Client

## 📋 Sobre o Projeto

Moto Finance é um sistema de controle financeiro desenvolvido para motoboys, permitindo o registro e acompanhamento de ganhos diários, gastos e lucro líquido de forma simples e intuitiva.

Status do Projeto: 🟢 Em desenvolvimento ativo

## 🚀 Tecnologias Utilizadas

Next.js 14 - Framework React com App Router

TypeScript - Tipagem estática

PrimeReact - Biblioteca de componentes UI

Tailwind CSS - Framework CSS utilitário

Context API - Gerenciamento de estado

Axios - Cliente HTTP

# Clone o repositório

git clone [seu-repositorio]

# Entre na pasta do client

cd client

# Instale as dependências

npm install

# Inicie o servidor de desenvolvimento

npm run dev

Acesse: http://localhost:3000
